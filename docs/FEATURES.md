# Feature-Stand

Alle ursprünglichen Anforderungen werden einzeln in GitHub Issues verfolgt. Implementierte Funktionen werden nach dem geprüften Push abgehakt und geschlossen; offene Funktionen bleiben offen.

| Issue | Feature | Implementierungsstand |
| --- | --- | --- |
| #1 | Accounts und clientseitig verschlüsselter Datentresor | Implementiert |
| #2 | Leiden und zugeordnetes Schmerzprotokoll | Implementiert |
| #3 | Medikamentenpläne und Einnahmeprotokoll | Implementiert |
| #4 | Erinnerungen bei geöffneter und entsperrter App | Implementiert |
| #5 | Zuverlässige Web-Push-Erinnerungen bei geschlossener PWA | Offen |
| #6 | Zyklus und Menstruationsbeschwerden protokollieren | Implementiert |
| #7 | Docker-App und responsive PWA bereitstellen | Implementiert |
| #8 | App in Flesh umbenennen | Implementiert |
| #9 | Installation unter ~/flesh, Port 8083 und Update-Skript | Implementiert |
| #10 | Neutrale Dokumentation und Feature-Issue-Workflow | Implementiert |
| #11 | Muskelfaser-Logo, PWA-Icons und Bordeaux-Farbschema | Implementiert |
| #12 | Updates im Home-Verzeichnis ohne Root-Pflicht | Implementiert |
| #13 | Bind-Adresse, Port und Registrierung per .env konfigurieren | Implementiert |

Die Detailkriterien und Prüfungen stehen in den jeweiligen Issues und in `.github/features.json`. Neue Feature-Anfragen erhalten ebenfalls ein eigenes Issue.
